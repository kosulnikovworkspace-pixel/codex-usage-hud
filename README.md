# Codex Usage HUD

Небольшое локальное расширение для Comet и других Chromium браузеров. Оно показывает поверх `chatgpt.com` использование 5-часового и недельного лимитов Codex, время до их сброса и число токенов за сегодня, когда эти данные доступны. HUD можно свернуть; его состояние и последний успешный результат сохраняются локально.

API key, отдельный backend, аккаунт расширения и сборка не нужны. Расширение не отправляет данные разработчику или стороннему серверу. Запросы идут только на `https://chatgpt.com` через уже открытую веб-сессию. Cookies и токены расширение не читает и не сохраняет.

## Установка

1. Откройте в Comet страницу управления расширениями через меню браузера.
2. Включите **Developer mode**.
3. Нажмите **Load unpacked**.
4. Выберите корневую папку `codex-usage-hud`, в которой лежит `manifest.json`.
5. Откройте или перезагрузите `https://chatgpt.com` после входа в свой аккаунт.

В другом Chromium браузере шаги те же. При изменении файлов нажмите **Reload** на странице расширений и перезагрузите вкладку ChatGPT. Чтобы удалить расширение, нажмите **Remove** на этой же странице.

## Откуда берутся данные

`src/usage-client.js` запрашивает два внутренних адреса ChatGPT: `/backend-api/wham/usage` для лимитов и `/backend-api/wham/analytics/daily-workspace-usage-counts` для токенов. Запросы выполняются из content script с `credentials: include` на том же сайте. Модуль принимает только проверенные числовые и временные поля и передаёт интерфейсу нормализованный результат. Если поле не распознано, HUD показывает `—`. При ошибке последнего запроса сохраняется прежний результат и появляется короткий статус.

Эти endpoints **не являются публичным стабильным API**. Их схему и требования к авторизации необходимо подтвердить в действующей сессии Comet. В окружении разработки не было доступа к авторизованной сессии ChatGPT, поэтому реальный ответ пока не проверен. Если endpoint требует особый механизм авторизации, который не обеспечивается обычным same-origin запросом с cookies, данные не загрузятся: расширение не извлекает bearer token из страницы и не обходит этот механизм.

Число токенов выводится только при наличии явного поля общего количества токенов за текущую локальную дату. Строки, явно помеченные как другой продукт, исключаются. Отсутствие подходящих строк не приравнивается к нулю.

## Если данные не загружаются

Проверьте, что вы вошли на `chatgpt.com`, затем нажмите **Refresh** (круговая стрелка). Если отображается `Usage data unavailable`, откройте страницу расширений и проверьте, что расширение включено. Если проблема сохраняется, внутренний endpoint мог изменить формат или правила доступа. Для исправления обычно достаточно обновить `src/usage-client.js`; менять HUD не требуется. Не публикуйте ответы API, cookies или заголовки авторизации при диагностике.

## Файлы и проверки

- `manifest.json` — Manifest V3; единственное permission — `storage`, доступ content script ограничен `https://chatgpt.com/*`.
- `src/usage-client.js` — запросы и нормализация ответов.
- `src/format.js` — форматирование значений.
- `src/content.js`, `src/hud.css` — HUD, обновление, сохранение состояния и темы.
- `test/usage.test.js` — тесты без сторонних зависимостей.

Проверки: `node --test test/*.test.js`, `node --check` для каждого JS-файла, а также JSON-проверка `manifest.json`. Папку проекта можно напрямую передать в **Load unpacked**.
